# 黄昏杯 部署速记（bsrserver.org.cn:5173）

生产形态：nginx 容器（443，对外 5173）全托管 —— 前端静态（`/data/twilight_cup/web`）+
REST 反代（`/api/` → 宿主机 8100，剥前缀）+ WS 反代（`/ws/`）+ 对象存储公开读
（`/assets/` → SeaweedFS 桶 `twilightcup`）。后端 uvicorn 跑在宿主机 tmux 会话 `twilightcup`。
Mongo / SeaweedFS / nginx 由 `/data/dockers/twilight_cup/docker-compose.yml` 编排。

## 一次性上线（生产 infra，需 sudo 手动执行）

```bash
# 1) 前端静态目录
sudo mkdir -p /data/twilight_cup/web
sudo chown -R heyblack:xiaohuihui /data/twilight_cup/web
rsync -a --delete ~/dev/TwilightCup/Web/TwilightCupFrontend/dist/ /data/twilight_cup/web/

# 2) 编辑 compose：nginx 服务 volumes 增加 web 根挂载 + extra_hosts（其余原样保留）
sudoedit /data/dockers/twilight_cup/docker-compose.yml
#    volumes 追加一行：
#      - /data/twilight_cup/web:/usr/share/nginx/html:ro
#    与 ports 同级追加：
#    extra_hosts:
#      - "host.docker.internal:host-gateway"

# 3) 重建 nginx（加载新挂载；conf.d 当前为空，无流量影响）
docker compose -f /data/dockers/twilight_cup/docker-compose.yml up -d

# 4) 放置站点配置并加载
sudo cp ~/dev/TwilightCup/Web/TwilightCupBackend/deploy/twilightcup.conf /data/twilight_cup/nginx/twilightcup.conf
docker compose -f /data/dockers/twilight_cup/docker-compose.yml exec nginx nginx -t
docker compose -f /data/dockers/twilight_cup/docker-compose.yml exec nginx nginx -s reload
```

## 日常运维

```bash
# 后端（tmux 会话 twilightcup，工作目录 = 仓库根，.env/logs 相对它）
tmux new-session -d -s twilightcup -c ~/dev/TwilightCup/Web/TwilightCupBackend \
  '.venv/bin/python -m twilightcupbackend.main'
tmux attach -t twilightcup                        # 查看（Ctrl-b d 退出）
tmux kill-session -t twilightcup                  # 停止

# 更新前端：构建 + 同步（产物目录是 static/，不是默认的 assets/）
cd ~/dev/TwilightCup/Web/TwilightCupFrontend && npm run build
rsync -a --delete dist/ /data/twilight_cup/web/

# 改 nginx 配置后
docker compose -f /data/dockers/twilight_cup/docker-compose.yml exec nginx nginx -t
docker compose -f /data/dockers/twilight_cup/docker-compose.yml exec nginx nginx -s reload
# 注：/assets/ 反代用容器名 seaweedfs，重建 seaweedfs 容器后需 reload nginx

# 日志
tail -f ~/dev/TwilightCup/Web/TwilightCupBackend/logs/twilightcup.log   # 后端
docker compose -f /data/dockers/twilight_cup/docker-compose.yml logs -f nginx
```

## 环境备忘

- 后端 `.env`（仓库根，gitignored）：Mongo `authSource=admin`、`PORT=8100`（8000 被
  spring 占用）、S3 指向 SeaweedFS `127.0.0.1:8333`（匿名模式，凭证留空）、
  `S3_PUBLIC_BASE_URL=https://bsrserver.org.cn:5173/assets`。
- Python 3.14.7 取自 `python:3.14-slim-bookworm` 镜像，前缀在
  `~/.local/share/py314`；uv 在 `~/.local/bin/uv`。本机 PyPI 走阿里云镜像：
  `UV_DEFAULT_INDEX=https://mirrors.aliyun.com/pypi/simple/`。
- 证书 `/var/www/cert/bsrserver.org.cn.pem|.key`，2026-10-21 到期，续期后
  `sudo cp` 覆盖 + reload nginx。
- SeaweedFS S3 网关当前匿名开放读写（0.0.0.0:8333）——按用户决定保持现状。
