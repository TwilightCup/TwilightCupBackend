# 系统消息本地化（语言文件）

服务器发给用户的 WS 系统消息（`system` 广播与 `error` 单播）从语言文件加载，
按比赛切换语言。REST 接口的 HTTP 错误消息不在本地化范围内。

## 文件格式

语言文件位于 `locales/` 目录（可用环境变量 `LOCALES_DIR` 覆盖路径），
**文件名即语言 id**（如 `en.txt`、`zh.txt`），UTF-8 文本，每行一条：

```
key = value
```

- `#` 或 `//` 开头为注释行，空行跳过；
- 每行按**首个 `=`** 切分键值，两端空白去除；
- value 中的占位符用 Python `str.format` 风格：`{player}`、`{value}`、
  `{s:02d}`（支持格式规格）；
- 重复键后者覆盖前者并记 warning 日志。

## 加载与回退

- 应用启动时（lifespan）一次性加载目录下全部 `*.txt`，不做热加载——
  修改文件需重启服务；
- 渲染回退链：**当前语言 → 默认语言（`DEFAULT_LOCALE`，默认 `en`）→ 键名本身**；
- 缺参数时占位符原样保留（如 `{player}`），渲染永不抛异常；
- 握手期（连接鉴权、比赛解析）尚无比赛状态，一律按默认语言渲染。

## 切换语言

裁判在比赛中发送聊天命令：

```
!lang          # 列出可用语言
!lang zh       # 切换到中文（即时生效，系统消息按新语言渲染）
!lang xx       # 无效 id → 错误提示并列出可选项
```

语言是**比赛级内存态**（存于每场比赛的实时状态，全场广播共用一种语言），
服务重启后回到默认语言。

## 添加新语言

1. 在 `locales/` 新建 `<id>.txt`（如 `ja.txt`），从 `en.txt` 复制全部键并翻译；
2. 重启服务，裁判 `!lang <id>` 即可使用；
3. 新增消息键时，`en.txt`（默认语言/回退源）必须包含该键，其余语言同步维护。
